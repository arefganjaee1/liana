# محصول دسته موجودی نزدیک‌ترین انقضا وضعیت
هنوز محصولی ثبت نشده. اوّل محصولاتی که استفاده می‌کنید رو با «افزودنِ محصول» اضافه کنید (مثلاً بوتاکس دیسپورت، به واحد)،
بعد هر خرید رو با «ورودِ خرید» ثبت کنید.

افزودنِ محصول

واحد همونیه که هم خرید و هم مصرف باهاش ثبت می‌شه. مثلاً اگه بوتاکس رو به «واحد» تزریق می‌کنید، یه ویالِ ۱۰۰ واحدی رو موقعِ خرید «۱۰۰» وارد کنید.
