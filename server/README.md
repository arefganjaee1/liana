# liana-server

بک‌اندِ لیانا — Express + SQLite (`node:sqlite`، بدونِ هیچ پکیجِ نیتیوِ اضافه).

## وضعیت

**فازِ ۱ (پنلِ مدیریتِ خدمات) آماده‌ست:**
- لاگین/سشن برای پنلِ مدیریت (دوتا نقش: `admin` و `manager` — ادمین به همه‌چی دسترسی داره)
- مدیریتِ پرسنل + ساعاتِ کاریِ هفتگیِ هرکدوم
- مدیریتِ خدمات: عنوان/توضیح/دسته‌بندی/قیمت/مدت‌زمان، variantها (مثلاً چند حالتِ یه خدمت)، پرسنلِ انجام‌دهنده، و عکس (نمونه/قبل/بعد/تجهیزات)
- یه endpoint عمومیِ فقط‌خواندنی (`/api/public/services`) برای مصرفِ سایت تو فازِ بعدی (موتورِ رزرو)

فازهای بعدی (رزرو، پنلِ نوبت‌ها، CRM، حسابداری) روی همین اسکلت ساخته می‌شن.

## اجرای لوکال

```bash
npm install
cp .env.example .env
node scripts/create-admin.mjs <username> <password> admin "اسمِ نمایشی"
npm run dev
```

بعد:
- سلامت‌سنجی: `curl http://localhost:3001/api/health`
- پنلِ مدیریت: `http://localhost:3001/admin/` (با یوزر/پسی که بالا ساختی وارد شو)

## دیپلوی روی سرور (بعداً)

همون الگوی gharzi: `pm2` برای نگه‌داشتن پروسه زنده + `nginx` به‌عنوان reverse proxy جلوش.
فایل دیتابیس (`data/liana.db`) و عکس‌های آپلودی (`data/uploads/`) عمداً commit نمی‌شن (تو `.gitignore`ن) —
رو هر محیطی جدا ساخته می‌شن. بعدِ اولین دیپلوی، حتماً یه‌بار `create-admin.mjs` رو رو سرورِ واقعی اجرا کن
تا حسابِ ادمینِ واقعی ساخته بشه (رمزِ تستِ لوکال رو رو سرور استفاده نکن).
