# لیانا

سایت + سیستم حساب مشتری کلینیک زیبایی لیانا (دکتر فرناز گنجایی).

## ساختار پروژه

```
site/
  index.html               → هوم‌پیج عمومی (پیش‌فرض سایت) — استاتیک، بدون نیاز به بک‌اند
  assets/                   → عکس‌ها و لوگوی هوم‌پیج
  service-botox-filler.html → صفحه‌ی خدمت بوتاکس/فیلر — هنوز ماکته (دیتای داخلش فرضیه‌ست، نه واقعی)
  liquid/                   → کاندید طراحی قدیمی (Liquid Glass)، کنار گذاشته شده، فقط برای آرشیو

server/            → بک‌اند (Express + SQLite) — اسکلت اولیه
  src/
    index.js        نقطه‌ی ورود، routeها
    db.js            اتصال به SQLite
  data/              فایل دیتابیس (commit نمی‌شه)
```

**⚠️ هنوز مونده:** `site/service-botox-filler.html` هنوز پر از دیتای فرضیه/جای‌خالیه (قیمت، مدت جلسه، توضیح خدمت — همه براکت‌دار و فرضی) و خودش بنر «ماکت طراحی» رو نگه داشته. **دیگه از هیچ‌جای هوم‌پیج بهش لینک داده نمی‌شه** — بوتاکس و فیلر تو هوم‌پیج (هیرو، مینی‌گرید، کاتالوگ خدمات) الان مثل بقیه‌ی خدمات با چیپ «به‌زودی» نشون داده می‌شه (عکس واقعیش رو نگه داشته، فقط لینک نداره). خودِ فایل تو ریپو می‌مونه برای وقتی دیتای واقعی آماده شد.

## اجرای لوکال

هوم‌پیج (`site/index.html`) یه فایل استاتیکه. دو تا راه برای دیدنش داری:

- **دابل‌کلیک رو خودِ فایل** — تو مرورگر باز می‌شه، ولی آدرسش با `file://` شروع می‌شه نه یه
  URL واقعی مثل `http://localhost:...`.
- **سرو کردن با یه static server، برای داشتن یه URL واقعی لوکال:**
  ```bash
  cd site
  npx --yes serve -l 5500
  ```
  بعدش تو مرورگر برو به `http://localhost:5500`. (اولین بار که `npx serve` رو می‌زنی، یه پکیج
  کوچیک دانلود می‌شه — بعدش سریعه.) با `Ctrl+C` می‌تونی متوقفش کنی.

بک‌اند:

```bash
cd server
npm install
cp .env.example .env
npm run dev
```
